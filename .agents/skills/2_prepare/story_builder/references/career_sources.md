> an interview is the one place a fabricated metric gets caught live, so the bar is *highest* here.

## The Prime Directive
**Never invent a metric, name, date, quote, or outcome.** A Story is a *neutral recording of what actually happened*; the only thing that flexes per question is which Principle lens you tell it through (see `principle_library.md`). If a Story would be stronger with a detail you can't trace:
- Use the qualitative version, OR
- Insert `[NEEDS INPUT: <what's missing — e.g., exact false-refusal % for Llama Guard>]` and list it in the generated story's Reflection/gaps so Vikash fills it before practicing.

A `[NEEDS INPUT]` marker is a 30-second fix. A made-up number that collapses under interviewer pushback (and these interviewers *do* push — see the sample) is a credibility kill.
