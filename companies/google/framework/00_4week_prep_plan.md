## 👥 Group Prep Playbook

This plan is designed for **group study**. The group amplifies every dimension — you get realistic interviewers, diverse feedback, and the pressure of performing live.

### Recommended Group Structure

| Element | Recommendation |
|---------|---------------|
| **Group Size** | 3-4 people ideal (enough for rotation, small enough for depth) |
| **Weekly Sync** | 1× per week — align on that week's pillar focus, share frameworks |
| **Mock Days** | Days 3, 7, 11, 13, 15 are designed as **group session days** |
| **Roles** | Rotate: Candidate / Interviewer / Observer every round |

### The Round-Robin Mock Format

Each group session, rotate through these roles:

```
         ┌──────────────┐
         │  CANDIDATE    │ ← Answers the question (35 min)
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │  INTERVIEWER  │ ← Asks the question, probes, pushes back
         └──────┬───────┘
                │
         ┌──────▼───────┐
         │  OBSERVER(S)  │ ← Silent. Takes notes. Scores on rubric.
         └──────────────┘

After each round: 10 min structured debrief
  • Observer shares notes FIRST (unbiased)
  • Interviewer shares follow-up quality assessment
  • Candidate self-reflects LAST
```

### Group Scoring Rubric (Use This Every Mock)

Score each dimension 1-5 after every mock round:

| Dimension | 1 (Weak) | 3 (Acceptable) | 5 (Strong) |
|-----------|----------|----------------|------------|
| **Structure** | No framework, rambling | Framework used but loosely | Clean framework, MECE |
| **User Focus** | No user segments defined | Users mentioned but generic | Specific segments + pain points before solutions |
| **Depth** | Surface-level, no follow-through | Reasonable depth | Probed own answer, discussed tradeoffs |
| **10x Thinking** | Incremental only | One bold idea among safe ones | Led with moonshot, then scoped to MVP |
| **Metrics** | No mention of measurement | Generic metrics | HEART framework, counter-metrics, specific targets |
| **Communication** | Unclear, too long | Clear but monotone | BLUF, concise, strong close, checked in with interviewer |

### Group Session Formats by Week

| Week | Group Session Focus | Format |
|------|-------------------|--------|
| **Week 1 (Day 3)** | Product Vision round-robin | Each person answers a cold design prompt while others interview/observe |
| **Week 2 (Day 7)** | Estimation hot-seat | Rapid-fire Fermi problems — each person gets 10 min, group critiques assumptions |
| **Week 3 (Day 11)** | Behavioral story swap | Each person delivers their best and weakest STAR story — group gives Googleyness feedback |
| **Week 4 (Days 13+15)** | Full loop simulation | Run a 4-round onsite loop with group members as interviewers for each round |

### Group Accountability

- [ ] **Shared question bank**: Each member contributes 5 questions per week to a shared doc
- [ ] **Weekly retro**: End each week with a 15-min group call — what improved, what still needs work
- [ ] **Peer scoring**: Track scores across weeks to visualize improvement
- [ ] **Pre-game cards**: Share your cheat sheets with each other in Week 4 — cross-pollinate frameworks
